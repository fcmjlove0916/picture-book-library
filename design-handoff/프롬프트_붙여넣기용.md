# 안티그래비티에 붙여넣을 프롬프트 (순서대로 1 → 2 → 3, 하나 끝날 때마다 화면 확인)

## 사전 준비 (내가 직접)
1. 이 폴더(`picture-book-design4`)를 통째로 프로젝트 폴더 `picture-book-library` 안에 넣습니다. 이름은 `design-handoff`로 바꿔도 좋습니다.
2. 안티그래비티에서 프로젝트를 열고 에이전트 창을 엽니다.
3. 아래 프롬프트 1번부터 붙여넣고 Enter. Allow 창이 뜨면 Allow.

---

## 프롬프트 1 — 폰트와 기본 틀
```
프로젝트 안의 design-handoff/HANDOFF.md 를 먼저 끝까지 읽고, design-handoff/reference/design4-reference.html 도 읽어 줘. 이번 작업은 "화면 디자인 바꾸기"이고 기능은 절대 바꾸지 않는 작업이야. 규칙은 HANDOFF.md 0번 항목을 따라.

지금은 1단계(글꼴과 기본 틀)만 해 줘.
1. design-handoff/fonts/KyoboHandwriting2019-subset.woff 파일을 public/fonts/ 폴더로 복사해 줘. 원본 .ttf 파일은 프로젝트에 넣지 마.
2. src/app/layout.tsx 에서 next/font/local 로 교보 손글씨(변수 이름 --font-hand), next/font/google 로 Noto Sans KR(weight 400, 500, 600, 700, 변수 이름 --font-sans)을 불러와서 html 또는 body 에 className 으로 적용해 줘. <html lang="ko"> 는 유지하고, metadata 의 title 은 "우리 반 그림책 도서관" 으로 바꿔 줘.
3. src/app/globals.css 에 HANDOFF.md 2번 표의 색상을 Tailwind v4 @theme(또는 CSS 변수)로 등록하고, body 에는 배경 #FFF7F0, 글씨색 #3A3350, 글꼴 var(--font-sans), font-synthesis: none 을 넣어 줘. 손글씨를 쓰는 곳에서 쓸 수 있게 .font-hand { font-family: var(--font-hand), var(--font-sans), sans-serif } 도 만들어 줘.
4. layout.tsx 의 body 에 있던 bg-slate-50 같은 옛 배경 클래스는 지워 줘.
끝나면 npm run build 를 실행해서 오류가 없는지 알려 줘. page.tsx 는 아직 건드리지 마.
```

## 프롬프트 2 — 메인 화면(page.tsx)
```
design-handoff/HANDOFF.md 의 3번(모양 규칙)과 4번(화면 구성)을 따라서 src/app/page.tsx 의 메인 화면 디자인을 바꿔 줘. 기준 화면은 design-handoff/reference/design4-reference.html 이야.

꼭 지킬 것:
- 상태(state), 필터·검색 계산, 대여 처리, fetch('/api/rent') 호출, 수량 증감 로직은 한 글자도 바꾸지 마. className 과 마크업 구조, 글꼴, 색, 크기만 바꿔.
- 책 표지는 지금처럼 실제 사진(<img>, referrerPolicy="no-referrer", 오류 시 coverEmoji 대체)을 쓰고, 비율은 3:4, 모서리 28px 로 해 줘. "표지 사진 자리" 같은 문구는 넣지 마.
- 통계 3칸 숫자는 기존에 계산하던 값을 그대로 쓰고, 글꼴은 Noto Sans KR Semibold 로 해 줘.
- 손글씨(font-hand)를 쓰는 곳과 Noto Sans KR 을 쓰는 곳은 HANDOFF.md 1번 표를 그대로 따라 줘.
- 이모지로 장식하지 말고, 구름 장식은 reference 파일의 SVG 를 가져다 써 줘.
- 아직 모달(빌리기 창, 완료 창)은 건드리지 마.
끝나면 npm run build 를 실행하고, 화면에서 확인할 점을 3줄로 알려 줘.
```

## 프롬프트 3 — 빌리기 창과 완료 창
```
design-handoff/HANDOFF.md 의 5번(빌리기 창)과 6번(빌렸어요 창)을 따라 src/app/page.tsx 안의 두 모달 디자인만 바꿔 줘. 기준 색과 모양은 같은 파일의 2번, 3번 항목이야.

꼭 지킬 것:
- 모달 열고 닫기, 입력값 검사, 오류 문구, 제출 처리(isSubmitting), 성공 후 수량 감소, 완료 창에 보여주는 책 제목과 반납일 값은 기존 코드를 그대로 써. 디자인(className, 마크업)만 바꿔.
- 입력칸·버튼 높이는 52px 이상, 글꼴은 HANDOFF.md 1번 표를 따라.
- 창 바깥을 누르면 닫히는 기존 동작은 유지해 줘.
끝나면 HANDOFF.md 7번 체크리스트를 하나씩 직접 확인하고(npm run build 포함), 안 맞는 항목이 있으면 고친 뒤 결과를 알려 줘.
```

## 끝난 뒤 (내가 직접 확인)
1. 터미널에서 `npm run dev` → http://localhost:3000 열어서 눈으로 확인합니다.
2. 책 한 권을 빌려 보고, 구글 시트에 한 줄 추가되는지 봅니다.
3. 괜찮으면 안티그래비티에게 "변경한 파일 목록과 커밋 메시지를 알려줘" 라고 하고 GitHub 에 올립니다. `.env` 는 올리지 않습니다.
4. 글씨가 이상하게 나오는 책 제목이 있으면 그 책 이름을 알려 주세요. (교보 손글씨에 없는 드문 글자는 자동으로 고딕체로 나옵니다)
