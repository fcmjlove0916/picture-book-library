# 디자인 4 (파스텔) 적용 핸드오프 — 우리 반 그림책 도서관

대상 프로젝트: `picture-book-library` (Next.js 16 App Router + TypeScript + Tailwind v4)
적용 범위: `src/app/layout.tsx`(폰트), `src/app/globals.css`, `src/app/page.tsx`, 빌리기 창, 빌렸어요(완료) 창
기준 화면: `reference/design4-reference.html` (브라우저로 열어서 보면 목표 화면과 같습니다)

## 0. 절대 지킬 것 (기능은 건드리지 않기)
- 동작은 그대로: 상태(state), 필터, 검색, 대여 처리, `/api/rent` 호출, 수량 증감 로직은 수정 금지.
- `src/app/api/rent/route.ts`, `data/books.js`, `.env`는 수정 금지. `.env`는 절대 커밋 금지.
- 바꾸는 것은 className, 마크업 구조, 글꼴, 색, 크기뿐입니다.
- 이모지로 꾸미지 않기. 아이콘은 SVG로 합니다. (단, 표지 사진이 안 뜰 때 쓰는 기존 coverEmoji 대체 표시는 그대로 유지)
- 유아·교사가 쓰는 화면이라 버튼과 터치 영역은 높이 52px 이상.

## 1. 글꼴 규칙
| 용도 | 글꼴 | 굵기 |
|---|---|---|
| 기본 글씨(본문, 필터 버튼 글씨, 작가 이름, 입력칸 안내문) | Noto Sans KR | 400 / 500 / 700 |
| 손글씨(로고 글씨, 안내 말풍선, 큰 제목, 책 제목, 주제 칩, 남은 책 배지, 빌리기 버튼, "친구가 대여 중", 모달 제목) | 교보 손글씨 2019 (`KyoboHand`) | 한 가지 굵기만 있음 → `font-synthesis: none` 필수 |
| 통계 칸(보유 도서·대여 가능·대여 중) | 전부 Noto Sans KR. 숫자는 Semibold(600) | 숫자 35px, "권" 18px, 라벨 16px |

- 교보 손글씨는 굵기가 한 가지뿐입니다. `font-weight`를 900으로 써도 굵어지지 않게 `font-synthesis: none`을 body에 넣습니다.
- 파일 위치: `public/fonts/KyoboHandwriting2019-subset.woff` (약 0.4MB, 한글 2,350자·영문·숫자 포함, 웹용으로 가볍게 줄인 파일)
- Noto Sans KR은 `next/font/google`로 불러옵니다. weight는 `400, 500, 600, 700`.
- 두 글꼴 모두 CSS 변수로 만듭니다: `--font-hand`, `--font-sans`.
- 손글씨에 없는 글자는 자동으로 Noto Sans KR로 대신 나오도록 `font-family: var(--font-hand), var(--font-sans), sans-serif`로 씁니다.

## 3. 모양 규칙
- 모서리: 버튼·칩·통계 칸은 완전 둥글게(`rounded-full`), 카드 36px, 표지 28px.
- 그림자: 평평한 "아래쪽 두꺼운 그림자" 방식. 번지는 그림자 쓰지 않기.
  - 카드 `0 10px 0 -2px rgba(120,100,170,.14)`
  - 흰 칩/통계 `0 5px 0 -1px rgba(120,100,170,.18)`
  - 빌리기 버튼 `0 7px 0 -1px rgba(60,40,140,.35)`
- 최대 너비 1120px, 좌우 여백 40px, 카드 3열(작은 화면 1~2열), 카드 간격 가로 28px / 세로 34px.
- 구름 SVG 장식 2개(오른쪽 위, 왼쪽 가운데)는 `reference` 파일의 SVG를 그대로 가져다 쓰고, 클릭을 막지 않게 `pointer-events-none`.

## 4. 화면 구성 (위에서 아래로)
1. **머리글**: 왼쪽 로고(56px 라일락 둥근 네모 + 책 SVG + "그림책 도서관" 손글씨 26px), 오른쪽 흰색 둥근 버튼 "책 둘러보기"(목록으로 부드럽게 이동).
2. **소개 영역**(가운데 정렬): 분홍 말풍선 "오늘은 어떤 그림책을 읽어 볼까?"(손글씨 19px) → 큰 제목 "우리 반 **그림책 도서관**"(손글씨 80px, 강조어는 primary 색) → 안내문 "읽고 싶은 책의 [빌리기] 단추를 꾹 눌러 보세요!"(22px, 빌리기는 노란 형광펜).
3. **통계 3칸**: 알약 모양 3개. 라벨 16px + 숫자 35px(Semibold) + "권" 18px, 글자 아랫선(baseline)을 맞춤. 숫자는 기존 계산값(전체/대여 가능/대여 중)을 그대로 사용.
4. **필터 줄**: 전체·동물·가족·친구·감정·자연 칩(높이 54px, 선택된 칩은 primary 바탕 흰 글씨) + "빌릴 수 있는 책만 보기" 민트 알약(체크박스 26px). 검색창이 이미 있으면 같은 둥근 스타일로 이 줄 옆에 유지.
5. **책 카드 3열**:
   - 위: 표지 영역. 실제 교보문고 표지 사진을 쓰므로 비율 3:4, 모서리 28px, `object-cover`, 기존 `referrerPolicy="no-referrer"`와 오류 시 coverEmoji 대체 유지. 왼쪽 위에 주제 칩(흰색 반투명, 손글씨 16px)을 겹쳐 놓음. "표지 사진 자리" 문구는 쓰지 않음. 사진이 없을 때만 cover1~6 색 바탕에 이모지.
   - 책 제목: 사진 아래, 손글씨 27px.
   - 한 줄: 왼쪽 작가(18px), 오른쪽 배지 — 대여 가능이면 민트 "남은 책 N권", 0권이면 회색 "다 빌려갔어요".
   - 버튼: 대여 가능이면 primary 빌리기 버튼(높이 68px, 손글씨 26px, 전체 너비), 없으면 회색 상자 "친구가 대여 중"(높이 68px, 눌러도 반응 없음).
   - 다 빌려간 카드는 전체를 `opacity-60`.

## 5. 빌리기 창(모달) — 같은 말투로 확장
- 바탕 가림막: `rgba(58,51,80,.45)`, 창 바깥을 누르면 닫힘(기존 동작 유지).
- 창: 흰색, 모서리 36px, 안쪽 여백 28px, 최대 너비 480px, 카드 그림자 규칙 사용.
- 맨 위: 작은 표지 사진(가로 72px, 3:4) + 책 제목(손글씨 28px) + 작가(16px).
- 입력칸 2개(빌리는 친구 이름, 반납 예정일): 라벨 16px 700, 입력칸 높이 56px, 모서리 999px(둥글게), 테두리 2px `#D9D2F7`, 글씨 20px, 포커스 시 테두리 primary + 바깥 4px 연보라 링.
- 반납일 바로 선택 칩 3개("7일 뒤" 등 기존 `daysLater` 쓰는 기능이 있으면 그대로): 높이 48px 흰색 칩, 선택되면 primary.
- 오류 문구: error 색, 16px, 입력칸 바로 아래.
- 버튼 2개 가로로: 왼쪽 "취소"(gray-chip, 높이 60px), 오른쪽 "빌리기"(primary, 손글씨 26px, 높이 68px, 처리 중에는 흐리게 하고 글씨를 "기록하는 중…"으로).

## 6. 빌렸어요(완료) 창
- 같은 창 모양. 맨 위에 민트 원(96px) + 흰색 체크 SVG(굵은 선).
- 제목 "빌렸어요!" 손글씨 36px, primary 색.
- 본문: 책 제목(손글씨 24px) / "반납일은 ○월 ○일이에요."(기존 returnDate 값 사용, Noto Sans KR 20px).
- 버튼 1개: "확인" 전체 너비, primary, 높이 68px.

## 7. 확인 체크리스트 (끝나고 AI가 스스로 확인)
- [ ] `npm run build`가 오류 없이 끝난다 (Vercel은 `--webpack` 없이 빌드)

- [ ] 통계 3칸 숫자가 Semibold이고 글자 아랫선이 맞는다
- [ ] 카드 3열, 사진이 안 뜨면 색 바탕 + 이모지로 대체된다
- [ ] 빌리기 → 창 열림 → 이름·반납일 입력 → 완료 창 → 수량 1 줄어든다 → 구글 시트에 한 줄 추가
- [ ] 다 빌려간 책은 "친구가 대여 중"이고 눌러도 창이 열리지 않는다
- [ ] 모바일 폭(390px)에서도 가로로 넘치지 않는다
